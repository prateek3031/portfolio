# Prateek Nassa — Portfolio

A responsive, animated one-page developer portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For the best local experience, use VS Code with the Live Server extension.

## Deploy free
- **GitHub Pages:** Create a repository, upload `index.html`, `styles.css`, and `script.js`, then enable Pages in repository Settings.
- **Vercel:** Import the GitHub repository and deploy it as a static site (no build command needed).

## Personalize before publishing
- Check every resume detail and project description.
- Add actual project repository URLs to the project cards when available.
- Replace the email/LinkedIn/GitHub links if any should differ.
- Add a downloadable resume PDF if desired.

## Design notes
Original dark editorial design with acid-lime accents, oversized type, scroll reveals, looping ticker, interactive project visuals, responsive navigation, and reduced-motion support. Inspired by motion-forward portfolio design, without copying another site's layout or assets.
